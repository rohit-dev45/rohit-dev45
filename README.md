## Now

**Parampara** — living graph of Indian classical music  
guru · shishya · gharana · raga

CognoDB (openCypher over Bolt, official Neo4j driver).  
127 nodes. 244 relationships. Multi-hop teaching chains. Shortest path. A force-directed explorer you can click.

SQL can list who taught whom. It cannot walk a bloodline.
